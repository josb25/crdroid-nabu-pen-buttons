firmware: nabu: report decoded pen side buttons in NT36523 v25

The CSOT NT36523 v25 pen-report formatter clears the button field even
though the Dell PN7522W side buttons are decoded internally. The existing
driver already maps this field to BTN_STYLUS and BTN_STYLUS2.

Copy the decoded state into the normal report field while preserving the
adjacent battery value. Update both shared ILM CRCs and cascade header
CRCs. Exactly nine instruction bytes and sixteen CRC bytes change.

The firmware and NT36523 driver tree on the 17.0 baseline are identical
to the tested 16.0 baseline. Generation, section/header checksums, Intel
HEX validation and patch application checks pass.

Existing crDroid 12 temporary-boot testing with the original compiled
driver recorded 1891 valid pen packets and balanced events for both
buttons without extra internal-state SPI reads or detected faults. The
user also reports original first-generation Xiaomi pen buttons working
without Bluetooth. Android 17 has not been boot-tested for this change;
charging, suspend/resume and sustained use still need coverage.
