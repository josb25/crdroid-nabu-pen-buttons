firmware: nabu: backport NT36523 v25 pen side buttons to 16.0

Bring 16.0 into line with the firmware correction merged in 17.0 as
2d2bde2dc39df1d3ae91e8ba4aa3fd4e7a17581b. The resulting firmware file is
byte-identical to that upstream change.

The CSOT NT36523 v25 pen-report formatter clears the button field even
though the side buttons are decoded internally. Copy the decoded state
into the normal report field for the existing driver, and update both
shared ILM CRCs and cascade header CRCs. Exactly nine instruction bytes
and sixteen CRC bytes change. No driver changes are needed.

The 16.0 source baseline is the baseline used by the existing crDroid 12
test. The original compiled driver delivered both buttons in the Dell
PN7522W test without additional SPI reads or detected faults. The user
also reports original first-generation Xiaomi pen buttons working
without Bluetooth. Charging, suspend/resume and sustained use still
require regression coverage.
